## 🎯 简历三大项目

### 项目一：电信客户流失分析
- 月付流失率 42.7% vs 两年付 2.8%（χ²=1158.7, p<0.001）
- 混杂路径分析排除地区干扰
- 业务建议：推出首年优惠，预计降低流失 15%

### 项目二：新版商品详情页 A/B 实验 ⭐
- **分层随机化**（按新老用户 × 地区），SRM 卡方 p=0.869 证明分流正常
- **核心指标**（转化率）：A=5.89% → B=6.26%，绝对 +0.37pp，相对 +6.2%，Z=2.434, p=0.0149
- **护栏指标**（人均时长）：朴素 Welch t=32.0，CUPED 调整后 t=38.0，方差削减 27.9%（协变量 corr=0.525）
- **护栏指标**（人均GMV）：Welch t=4.320, p=1.56e-05，BH 校正后显著
- **HTE 异质性**：交互项 p=1.10e-06 高度显著，老用户 B-A +0.97pp，新用户 B-A -0.53pp
- **序贯检验**：5 次偷看 α=0.01，全程不显著（效应中等时真实场景）
- **上线建议**：老用户全量新版，新用户暂停 → 差异化上线
- **BI 仪表盘**：dashboard.html（交互式，可部署 GitHub Pages）

### 项目三：电商用户行为分析
- RFM 识别 8% 高价值流失预警用户
- 漏斗发现移动端支付流失 35%
- 建议：优化移动端支付，预计提升转化 1.2%
